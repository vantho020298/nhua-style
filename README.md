# Nhựa Style Barber Shop website

Static site (Astro 5) for Nhựa Style Barber Shop, four shops in Đà Nẵng, in 6 languages (vi, en, ja, ko, zh, ru). The look follows the shop's printed menu: cream paper, navy and oxblood. Services, team, products and posts are imported from the Nhựa Pro WordPress site.

## Commands

| Command | What it does |
|---|---|
| `npm install` | Install dependencies (Node 20+) |
| `npm run dev` | Local dev server at http://localhost:4321 |
| `npm run build` | Build the site into `dist/` (`/`, `/en/`, `/ja/` …), with sitemap and robots.txt |
| `npm run import:wp` | Re-import content and images from the current WordPress site |

Set `SITE_URL` to the site's domain (it defaults to `https://nhuaprobarbershop.com`).

Pushing to `main` publishes the site on GitHub Pages (`.github/workflows/pages.yml`), at `https://<owner>.github.io/<repo>/`. For a subfolder like that, the build takes `BASE_PATH=/<repo>`. The `dist/` folder can be uploaded to any static host.

## Where things live

- `src/data/*.json`: services, team, products, posts, pages, branches, videos, reviews. Generated by `scripts/import-wp.mjs` from the WordPress REST API; prices are read from the rendered catalog cards because the theme stores them outside post content.
- `src/config/site.ts`: name, email, WeChat account, social links, opening hours, the four shops (address, map, shared Zalo/WhatsApp number), analytics IDs (GA4 / Facebook Pixel are only loaded when filled in).
- `src/i18n/ui.ts`: all interface text in 6 languages.
- `src/styles/themes.css`: design tokens (colours, fonts, radii); `src/styles/global.css`: shared components.
- `src/components/home/HomeMenu.astro`: the homepage, laid out like the printed menu.
- `src/assets/photos/`: shop photos (from the owner's Drive) and the logo; `src/assets/media/`: images imported from WordPress. Astro converts them to AVIF/WebP at build time.

## Booking

There is no booking backend. The form builds a message (labels in Vietnamese plus the visitor's language) and opens WhatsApp with it pre-filled, or copies it and opens Zalo, or copies it and shows the WeChat QR code. Links such as `/booking/?service=combo-basic&barber=son-le&branch=nhua-style-tran-bach-dang` pre-fill the form.
